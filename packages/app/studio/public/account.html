Agent access

Connect your agent to your own openDAW tabs. Each account has separate credentials and sessions.

Open Studio

Agent credentials

Create a credential for each agent. Copy it now; it will only be shown once. Credentials expire after 30 days.

    

    Pair a Studio tab
    Generate a code, then open Studio in this tab. Choose Remote Control in the Studio menu, paste the code, and connect. Codes expire after 60 seconds and can only pair a tab signed into your account.
    

    Connected tabs
      Keep Studio open. Audio playback requires a click in Studio to enable audio. AWS connections end after two hours; generate a new code and pair again.
      

      MCP connection
      URL: https://gettelecode.com/remote-control/mcp
Transport: Streamable HTTP
Authorization: Bearer YOUR_AGENT_CREDENTIAL
      Your MCP client must support a custom Authorization header. It can discover tools, list your sessions, read project state, change tempo, and play or stop.
